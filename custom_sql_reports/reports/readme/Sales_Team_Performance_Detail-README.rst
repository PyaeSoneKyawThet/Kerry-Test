Business Workflow Summary (Project Handover – CZT, 25-06-2026)
-------------------------

Technical Name: sale_team_performance_detail

1. Overview
========================================

   | Detail Sales Team Performance by Revenue report for Odoo Sales.
   | This report provides a detailed breakdown of sales revenue
   | generated by each salesperson based on job orders, grouped
   | by month, business unit (BU), sub business unit (SubBU),
   | product, and currency.

   | It helps management analyze revenue contribution at a very
   | granular level.

2. Key Features
========================================

   | Wizard Filters
   |   - Start Date selection
   |   - End Date selection
   |   - Multiple Salesperson selection
   |   - Multiple Currency selection
   |   - Multiple Business Unit (BU) selection
   |   - Multiple Product selection

   | Revenue Analysis
   |   - Revenue grouped by Salesperson
   |   - Monthly revenue breakdown
   |   - Business Unit and Sub Business Unit tracking
   |   - Product-level revenue visibility
   |   - Multi-currency support

   | Job Order Based Reporting
   |   - Includes only Job Orders (`is_job_order = True`)
   |   - Considers confirmed and done orders only
   |   - Based on `job_date` field filtering

   | Excel Export
   |   - Generates Microsoft Excel (.xls) report
   |   - Downloadable directly from wizard
   |   - Includes company information
   |   - Includes report duration
   |   - Includes printed date and currency summary

3. Report Layout
========================================

   | Company Name
   | Report Title:
   |   "Detail Sales Team Performance by Revenue"

   | Report Header
   |   - Selected date range
   |   - Currency filter summary
   |   - Printed date and time

   | Report Columns
   |   - No
   |   - Sale Person
   |   - Job Month
   |   - BU
   |   - SubBU
   |   - Product Name
   |   - Total Amount
   |   - Currency Symbol

4. Column Description
========================================

   | No
   |   - Sequential row number for each record.

   | Sale Person
   |   - Name of the salesperson linked to the customer.
   |   - Retrieved via partner’s assigned salesperson.

   | Job Month
   |   - Month of the job order (`job_date`) in format "Mon YYYY".
   |   - Data is grouped monthly using `DATE_TRUNC('month', job_date)`.

   | BU
   |   - Business Unit category of the product.
   |   - Derived from product category (`product.category`).

   | SubBU
   |   - Sub Business Unit linked through analytic account mapping.
   |   - Extracted from analytic plan where plan name contains "subbu".

   | Product Name
   |   - Name of the product sold.
   |   - Taken from product template (`product.template`).

   | Total Amount
   |   - Total revenue generated from the sale order line.
   |   - Calculated using `SUM(sol.price_total)` grouped by filters.

   | Currency Symbol
   |   - Currency used for the transaction.
   |   - Helps identify multi-currency revenue records.

5. Business Benefits
========================================

   | Provides detailed visibility of sales revenue breakdown.
   | Helps track performance by salesperson and product.
   | Enables analysis by business unit and sub business unit.
   | Supports monthly revenue trend analysis.
   | Useful for financial and sales management reporting.

6. Technical Details
========================================

    | Data Source:
    | - Sales Orders (sale_order)
    | - Sales Order Lines (sale_order_line)
    | - Products (product.product / product.template)
    | - Product Categories (product.category)
    | - Analytic Accounts (account_analytic_account)
    | - Currency (res.currency)
    | - Users & Partners (res.users / res.partner)

    | Export Format:
    | - Microsoft Excel (.xls)

    | Filtering Behavior:
    | - If no filter is selected, system automatically includes all records
    | for that dimension (users, currency, BU, products)

    | Timezone Support:
    | - Printed date follows user timezone setting
